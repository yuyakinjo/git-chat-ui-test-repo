# git-chat-ui-test-repo

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

To generate local test branches for commit graph experiments:

```bash
./gen-test-branch 6
```

To clean up the generated local test branches:

```bash
./clean-up-test-branch
```

This project was created using `bun init` in bun v1.3.11. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
